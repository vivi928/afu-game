# afu-game
外送大叔出任務：爆走外送員

《外送大叔的逆襲》控制說明



如何開始遊戲


將遊戲原始碼存成 "外送大叔的逆襲.html"。
使用 Chrome、Edge 或 Safari 開啟。
點選「開始遊戲」。
首次播放音樂時，點擊右上角的「音樂」按鈕。
手機畫面較窄時，建議旋轉成橫向遊玩。


2. 手機操作



點擊地面：角色自動朝指定位置移動，綠色圈圈表示目標位置。
左下虛擬搖桿：拖曳控制角色方向，放開後停止。
吃便當：消耗便當並恢復體力。
投擲食物：投擲目前選擇的食物，引開附近野狗。
互動按鈕：靠近店家、顧客目的地、家門或加油站時使用。
故事：開啟主線故事。
操作：查看控制說明。
音樂：開啟或關閉原創合成音樂。


3. 電腦鍵盤操作



按鍵| 功能

W、A、S、D| 上、左、下、右移動

方向鍵| 移動

滑鼠左鍵| 點擊地面自動移動

E 或空白鍵| 互動、取餐、送達、進門

B| 吃便當

J| 投擲食物

Q| 切換食物

Y| 接受訂單

N| 拒絕訂單

M| 開啟故事

Esc| 關閉視窗



4. 外送流程



等待新訂單出現。
按「接受訂單」。
依照畫面上方的導航前往店家。
靠近店家後按互動鍵取餐。
導航會切換至顧客目的地。
抵達後再次互動，完成配送並領取報酬。


5. 道具與資源



體力：受到野狗攻擊時會下降。
汽油：移動時逐漸消耗；汽油耗盡後移動速度下降。
便當：可恢復體力。
珍珠奶茶：野狗定身約 4 秒。
香雞排：野狗定身約 8 秒。
貢丸：野狗定身約 3 秒。
加油站：靠近後按互動，可補滿汽油。
阿豪小窩：靠近後按互動，可進屋休息。
回家備餐：花費遊戲金錢，可增加便當與珍奶數量。
完成 3 單：解鎖快速回家功能的設計目標。


6. 主線故事



序章：還沒結束的一天
第一章：今天也要活下去
第二章：熟悉的陌生人
第三章：03:17
第四章：逆襲的真正意義


故事進度與部分選擇會保存在目前瀏覽器的本機儲存空間。這不是雲端存檔，無法自動跨裝置同步。



7. 版本範圍與注意事項



本版本是可遊玩的 HTML 原型，包含地圖、移動、接單、取餐、送達、基本資源、道具、野狗事件、故事視窗與音樂。



以下功能仍需後續擴充與測試：



完整 NPC 好感度、記憶與支線任務
真正的障礙物碰撞與智慧尋路
完整的迷你遊戲
完整多結局條件
雲端存檔與跨裝置同步
不同手機、平板與桌面瀏覽器的實機測試


若遊戲無法操作，請先確認瀏覽器已載入完整 HTML，並重新整理頁面。音樂播放需要使用者先點擊按鈕，部分瀏覽器才會允許播放。
